# calculator - Solidity

Smart contract of a basic calculator built with Solidity 0.8.24

## Functionalities
- Addition and subtraction of positive numbers (uint256)
- Subtraction with support for negative numbers (int256)
- Modifier for input validation
- Events for operation tracking on blockchain
- Public and internal functions

## Technologies
- Solidity 0.8.24
- Ethereum
- remix.ethereum.org
